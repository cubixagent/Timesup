# TimesUp ⏱️ — تایمزآپ

**اپلیکیشن هوشمند مطالعه برای کنکور**

> یه PWA آفلاین کامل برای ردیابی زمان مطالعه، تحلیل عملکرد، و انگیزه‌دهی به دانش‌آموزان کنکوری

---

## 🚀 نصب روی GitHub Pages

1. این ریپو رو fork کن
2. برو به **Settings > Pages**
3. Source رو روی **main branch** و **/ (root)** تنظیم کن
4. اپ رو از `https://username.github.io/timesup/` باز کن
5. از مرورگر موبایل، گزینه **Add to Home Screen** رو بزن

---

## ✨ ویژگی‌ها

- ⏱️ **تایمر دقیق** — کار در پس‌زمینه (تا ۳ ساعت)، توقف کوتاه، فونت‌های مختلف
- 📊 **داشبورد کامل** — نمودار هفتگی، هیت‌مپ حواس‌پرتی
- 🫣 **ردیاب حواس‌پرتی** — با یه کلیک ثبت می‌شه
- 📄 **گزارش PDF** — گزارش روزانه با تم متغیر بر اساس عملکرد
- 💙 **مراقبت از کاربر** — چک وضعیت صبح، بعدازظهر، شب
- 🔔 **اعلان‌ها** — حتی در شرایط اینترنت محدود ایران
- 💾 **بکاپ/ریستور** — خروجی JSON کامل
- 🔄 **آپدیت خودکار** — بدون پاک شدن داده‌ها

## 🔧 آپدیت برنامه

برای نمایش پیغام آپدیت به کاربران، فقط کافیه `version.json` رو ویرایش کنی:

```json
{
  "version": "1.1.0",
  "buildDate": "2026-06-01",
  "message": "ویژگی‌های جدید اضافه شد!"
}
```

کاربرانی که آنلاین هستن، پیغام آپدیت می‌بینن و می‌تونن بدون از دست دادن داده‌هاشون، برنامه رو ریلود کنن.

همچنین در `sw.js` مقدار `CACHE_NAME` رو تغییر بده:
```js
const CACHE_NAME = 'timesup-v1.1.0';
```

│   ├── pdf.js          # تولید PDF

└── icons/              # آیکون‌های PWA
